# 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on the Indian Premier League (IPL) dataset to uncover meaningful insights into team performance, player statistics, match outcomes, venue trends, and seasonal records.

Using Python and popular data analysis libraries, the project transforms raw IPL match data into actionable insights through statistical analysis and visualizations.

---

# 🎯 Objectives

- Analyze IPL match history
- Explore team performance across seasons
- Identify top-performing players
- Study toss impact on match outcomes
- Discover venue-wise winning trends
- Analyze seasonal statistics
- Visualize cricket insights using Python

---

# 📊 Dataset

The project uses IPL historical match datasets containing:

- Match Information
- Team Details
- Venue Information
- Toss Results
- Match Winners
- Player of the Match Awards
- Match Dates
- Season Information
