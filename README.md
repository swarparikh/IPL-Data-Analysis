# IPL-Data-Analysis

## Overview

This project is an end-to-end Power BI dashboard that I built to analyze data from the Indian Premier League (IPL). The main objective of the project was to take raw IPL data and turn it into a clean, interactive dashboard that highlights key trends related to teams, players, and match outcomes.

The project covers the complete Power BI workflow — from loading and cleaning the data to creating relationships, writing DAX measures, and designing the final dashboard.

## Project Details

I worked on this project to get hands-on experience with real-world data and understand how business intelligence tools like Power BI are used in practice. The focus was not just on visuals, but also on structuring the data properly so the insights are accurate and easy to explore.

The dashboard allows users to:
- Analyze team performance across seasons.
- Compare player statistics.
- View match-wise and season-wise trends.
- Interact with the report using filters and slicers.

## Features

- Data cleaning and transformation using Power Query.
- Proper data modeling with table relationships.
- DAX measures for key metrics.
- Interactive visuals and slicers.
- Clear and simple dashboard layout.
- IPL-specific performance insights.

##Dataset

The dataset used in this project contains historical IPL information such as:

- Match details
- Teams and venues
- Player performance statistics
- Match results

Basic data cleaning was required to handle missing values, rename columns, and structure the data for analysis.


## Using the Dashboard

Once the dashboard is loaded:

- Use slicers to filter by season, team, or player
- Compare team and player performances
- Explore trends across different IPL seasons

The dashboard is interactive and easy to use, even for someone without a technical background.
